VrFsim runs **standalone** on a Meta Quest: no PC while you play, no cable. Same game as the Windows version: the full BIOBUZZ field, real match flow and scoring, and the dsim-style robot builder.

If your PC can run Quest Link, the **Windows version** of VrFsim is the recommended one (better graphics, and the monitor shows what you see).

## How to install
1. Turn on **developer mode** for the headset (Meta Horizon phone app → Devices → Headset settings → Developer mode)
2. Connect the headset to this PC with a USB-C cable and press **Install on device**
3. In the headset, accept **Allow USB debugging** (tick *Always allow from this computer*)
4. Afterwards, find it in the headset under **Library → Unknown Sources → VrFsim**

## Controls
- **Quest Touch controllers:** left stick drives, right stick turns, triggers intake and fire, grips place POLLEN and shift, `A` starts the match, `≡` opens the menu
- **A gamepad over Bluetooth:** headset Settings → Devices → Bluetooth → Pair (Xbox and PlayStation controllers)
- **A controller plugged into a low-spec laptop:** use **VrFsim Controller Connect**

## System requirements
- Meta Quest 3, 3S, Pro or 2, with developer mode on

## What's new in 0.2.0
1. First standalone Quest version, with 72 / 90 / 120 Hz (Menu → Graphics) and foveated rendering
2. Drive with the Quest controllers, or any gamepad
